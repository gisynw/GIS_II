Points are symbolized by elevation: higher elevations appear warmer (red/yellow) and lower elevations appear cooler (blue/purple).

About

The UCA LiDAR Program showcases 3D point cloud visualization for campus-scale exploration and teaching. This site embeds an ArcGIS Online Web Scene to support interactive viewing and outreach.

Projects

Campus 3D Visualization

Use LiDAR point clouds to visualize campus features in 3D and support demonstrations in GIS, remote sensing, and spatial analysis courses.
